# Weather Diary — Дневник погоды

**Автор:** Саттаров Айзат 

## Описание
GUI-приложение на Python (tkinter) для ведения дневника погоды.  
Позволяет:
- Добавлять записи (дата, температура, описание, наличие осадков)
- Фильтровать записи по дате или по температуре (> +10°C)
- Сохранять и загружать данные в/из JSON-файла
- Проверять корректность ввода данных

## Как запустить
1. Убедитесь, что установлен **Python 3.6** или новее.
2. Скачайте файл `main.py` и поместите его в отдельную папку.
3. Откройте терминал в этой папке и выполните:
   ```bash
   python main.py
